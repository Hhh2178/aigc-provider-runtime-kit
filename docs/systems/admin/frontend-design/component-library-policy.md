# Component Library Policy

## Current Policy

No component library is bundled in v0.1.

If an admin example is added later, prefer:

- React + TypeScript
- Radix primitives or Ariakit for accessible behavior
- Project-owned tokens for color, radius, spacing, and typography

## Non-goals

- Do not bundle a heavy dashboard template into the core runtime kit.
- Do not make UI dependencies required for server-side users.
