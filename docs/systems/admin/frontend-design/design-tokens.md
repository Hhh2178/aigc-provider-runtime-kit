# Admin Design Tokens

This repository does not ship a production admin UI in v0.1. These tokens define the recommended visual direction for future examples.

| Token | Value | Usage |
| --- | --- | --- |
| `page.background` | `#f6f3ec` | App background |
| `panel.background` | `#fffaf0` | Cards and panels |
| `panel.border` | `#d8cbb7` | Soft structural borders |
| `text.primary` | `#231f1a` | Main text |
| `text.secondary` | `#6f6558` | Help text |
| `accent.primary` | `#0f766e` | Primary actions |
| `danger.primary` | `#b42318` | Destructive actions |
| `radius.panel` | `18px` | Panels |
| `radius.control` | `10px` | Inputs and buttons |
| `space.page` | `32px` | Page padding |
| `space.section` | `20px` | Section gap |
| `table.row.height` | `44px` | Data tables |
