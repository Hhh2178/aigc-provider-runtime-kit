# Visual Component Registry

Future admin examples should define these visual components before implementation:

| Component | Purpose | Notes |
| --- | --- | --- |
| Page shell | Global layout | Token-driven spacing |
| Provider card | Provider summary | Status, protocol, model count |
| Model table | Model governance | Capability tags and test state |
| Key pool panel | RunningHub keys | Hide real keys; show previews only |
| Execution log panel | Runtime evidence | Read-only by default |
| Save bar | Dirty state control | Explicit save/cancel |
