# Functional Component Registry

Future admin examples should reuse these functional components:

| Component | Inputs | Outputs | Permission Boundary |
| --- | --- | --- | --- |
| Provider editor | Provider draft | Provider definition | Admin only |
| Model schema editor | Model draft | Parameter schema | Admin only |
| RunningHub catalog editor | RH source | Catalog item | Admin only |
| Key pool editor | Key previews | Key pool config | Secret-aware admin only |
| Probe action | Provider config | Test result | Admin only |
